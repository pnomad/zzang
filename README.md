# 인형뽑기 연습기

실제 인형뽑기 기계의 물리와 기계 세팅(구간별 집게 힘, 확률, 가드 높이 등)을 재현한 3D 연습 게임입니다.

## 실행

- **간단히:** `실행.bat` 더블클릭 → 브라우저가 열립니다. (Node.js 필요)
- **직접:** `npm install` 후 `npm run dev`
- **배포용 빌드:** `npm run build` → `dist/` 폴더

## 조작

2D 오락실을 걸어 다니다가 하고 싶은 기계 앞에서 플레이하면, 그 기계가 3D 물리 화면으로 열립니다. 기계 위 간판에 경품 종류, 일반/미니, 난이도(★), 1회 가격이 적혀 있습니다.

**오락실에서**

| 키 | 동작 |
|---|---|
| 방향키 | 걷기 (대각선 포함) |
| Enter / Space | 앞에 있는 기계 플레이 |

**기계 앞에서**

| 키 | 동작 |
|---|---|
| Enter / Space | 동전 넣기, 이동 중에는 집기 |
| 방향키 | 집게 자유 이동 (기본) |
| → / ↑ | 한국식 2버튼 모드(세팅에서 선택): 누르고 있다 떼면 멈춤 (각 1번씩) |
| V | 시점 전환 (위에서 / 정면 / 옆에서 / 자유) |
| R | 방금 판 리플레이 (슬로모션) |
| Esc | 기계에서 나가기 |
| M | 소리 켜기/끄기 |

## 무엇이 재현되나요

- **기계 종류:** 실제 오락실처럼 한 기계에는 비슷한 크기의 경품만 넣음
  - 일반 기계: 일반 인형 / 큰 인형 / 큰 박스. 급출발·급정지라 줄이 잘 흔들림 (5~7°)
  - 미니 기계: 미니 인형 / 작은 박스 / 캡슐. 부드럽게 가감속해서 줄 흔들림 2° 이내
- **집게 대기 높이:** 실제 기계처럼 집게 끝이 경품 2.5개가 쌓인 높이쯤에 오도록 경품 크기에 맞춰 자동으로 정함. 구조 → 집게 대기 높이로 조절 가능 (탑쌓기 연습용)
- **경품:** 곰, 토끼(귀 걸기), 납작 쿠션, 롱 고양이, 대형 곰, 피규어 상자, 과자 상자, 키링(고리 걸기), 미니 인형, 미니 상자, 캡슐볼 — 무게·무게중심·마찰·말랑함이 각각 다름
- **집게 힘 = 구간별 전압:** 집을 때 / 올라갈 때 / 꼭대기 / 이동 중 힘을 따로 설정. 힘이 약하면 복귀 스프링 때문에 발이 헐거워짐
- **배출구 앞 힘 빠짐:** 집게가 배출구에 가까울수록 힘이 약해짐. 멀리 있는 건 잘 잡히지만 배출구 앞 경품은 잘 안 잡히고, 옮기다가도 배출구 앞에서 빠짐 (연습 모드에서 바닥에 주황색으로 표시)
- **확률(페이아웃):** N판마다 또는 누적 금액마다 강집게
- **줄 흔들림:** 갠트리가 출발·정지할 때 집게가 진자처럼 흔들림
- **실패 분석:** 빈 곳 집음 / 닿았지만 미끄러짐 / 상승 중 낙하 / 꼭대기 힘 빠짐 / 흔들림 낙하 / 가드 걸림 — 원인과 모양별 공략 팁, 힘·높이·흔들림 그래프
- **효과음:** 동전, 모터, 하강, 집게 닫힘, 성공/실패 (파일 없이 WebAudio로 합성)
- **연습 도우미:** 집게가 벌어졌을 때 닿는 범위를 경품 위에 원으로 표시, 무게중심 표시 (실전 모드에서는 꺼짐)
- **기록:** 시도·성공·지출과 결과별(실패 원인별) 횟수를 저장. 연습 세팅도 새로고침해도 유지
- **실전 모드:** 세팅이 숨겨진 무작위 기계. 다 하고 나서 "세팅 공개"로 정답 확인

## 구조

```
src/physics/   Rapier 월드, 충돌체+메시 파츠
src/machine/   세팅/프리셋, 캐비닛, 갠트리, 3발 집게
src/prizes/    경품 정의(모양별), 경품 생성(스프링 관절 부위)
src/game/      기계 조립(Rig), 게임 진행(Controller), 실패 분석/리플레이
src/lobby/     2D 오락실 화면(기계 배치, 간판, 캐릭터), 기계별 3D 기계 관리
src/ui/        HUD, 세팅 패널, 효과음, 조준 도우미
```
