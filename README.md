# 인형뽑기 연습기

실제 인형뽑기 기계의 물리와 기계 세팅(구간별 집게 힘, 확률, 가드 높이 등)을 재현한 3D 연습 게임입니다.

## 실행

- **간단히:** `실행.bat` 더블클릭 → 브라우저가 열립니다. (Node.js 필요)
- **직접:** `npm install` 후 `npm run dev`
- **배포용 빌드:** `npm run build` → `dist/` 폴더

## 조작

| 키 | 동작 |
|---|---|
| Enter | 동전 넣기 |
| → / ↑ | 한국식 2버튼: 누르고 있다 떼면 멈춤 (각 1번씩) |
| 방향키 + Space | 조이스틱 모드: 이동 후 집기 |
| V | 시점 전환 (정면 / 옆에서 보기 / 자유 시점) |
| R | 방금 판 리플레이 (슬로모션) |

## 무엇이 재현되나요

- **기계 종류:** 일반뽑기 / 미니뽑기 (크기, 집게, 경품 구성이 다름)
- **경품:** 곰, 토끼(귀 걸기), 납작 쿠션, 롱 고양이, 대형 곰, 피규어 상자, 과자 상자, 키링(고리 걸기), 미니 인형, 미니 상자, 캡슐볼 — 무게·무게중심·마찰·말랑함이 각각 다름
- **집게 힘 = 구간별 전압:** 집을 때 / 올라갈 때 / 꼭대기 / 이동 중 힘을 따로 설정. 힘이 약하면 복귀 스프링 때문에 발이 헐거워짐
- **확률(페이아웃):** N판마다 또는 누적 금액마다 강집게
- **줄 흔들림:** 갠트리가 출발·정지할 때 집게가 진자처럼 흔들림
- **실패 분석:** 빈 곳 집음 / 닿았지만 미끄러짐 / 상승 중 낙하 / 꼭대기 힘 빠짐 / 흔들림 낙하 / 가드 걸림 — 원인과 모양별 공략 팁, 힘·높이·흔들림 그래프
- **실전 모드:** 세팅이 숨겨진 무작위 기계. 다 하고 나서 "세팅 공개"로 정답 확인

## 구조

```
src/physics/   Rapier 월드, 충돌체+메시 파츠
src/machine/   세팅/프리셋, 캐비닛, 갠트리, 3발 집게
src/prizes/    경품 정의(모양별), 경품 생성(스프링 관절 부위)
src/game/      기계 조립(Rig), 게임 진행(Controller), 실패 분석/리플레이
src/ui/        HUD, 세팅 패널
```
